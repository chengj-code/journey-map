# 足迹地图 App - 功能规划路线图

> 基于当前已有功能（足迹地图 + 记账本）的补充方向规划

---

## P0 — 高优先级（与现有功能强联动、开发量小、用户价值大）

### 1. 💳 预算管理
- **描述**：在现有记账基础上增加预算控制能力
- **功能点**：
  - 设定月度/年度总预算额度
  - 设定分类预算（餐饮 ¥2000/月、交通 ¥500/月…）
  - 实时消费进度条展示（已花 / 预算）
  - 超支预警提醒（进度 > 80% 变黄，>100% 变红）
  - 预算周期切换（本月 / 本季 / 本年）
- **依赖**：记账模块（已有收支记录数据）
- **开发量**：⭐⭐ 中等
- **用户价值**：⭐⭐⭐⭐⭐ 极高 — 记账的天然闭环

### 2. 📝 日记 / 备忘录
- **描述**：生活文字记录模块，与足迹地图和记账本打通
- **功能点**：
  - 每条日记关联日期 + 地点（自动读取当前位置或手动选择）
  - 支持纯文字 + 图片附件
  - 支持标签分类
  - 时间线展示（按日/周/月聚合）
  - 与足迹联动：点亮某城市时可以写一篇游记
  - 与记账联动：一笔大额支出附带心情备注
- **依赖**：足迹地图（地点数据）、标签系统
- **开发量**：⭐⭐⭐ 较大
- **用户价值**：⭐⭐⭐⭐⭐ 极高 — "生活记录"的核心拼图

### 3. 📅 年度 / 月度报告
- **描述**：自动生成可视化总结报告
- **功能点**：
  - 月报：本月收支总览 + 支出 Top3 分类 + 足迹新增城市数
  - 年报：全年回顾 — 总支出、最常去的城市、最爱吃的分类
  - 可视化卡片设计（适合截图分享）
  - 支持 PNG 导出分享到朋友圈/社交媒体
  - 同比对比（比上月多花了 XX%）
- **依赖**：记账模块、统计图表（ECharts 已有）、足迹数据
- **开发量**：⭐⭐ 中等
- **用户价值**：⭐⭐⭐⭐ 很高 — 数据已有，缺的是呈现和传播

---

## P1 — 中优先级（丰富使用场景、提升粘性）

### 4. 🏷️ 全局标签系统升级
- **描述**：将标签从记账专属扩展为全局通用
- **功能点**：
  - 标签类型扩展：日记标签、账单标签、习惯标签统一管理
  - 标签聚合页：点击 `#旅行` 看到所有相关内容（日记+账单+地点）
  - 标签云 / 热力图展示常用标签
  - 标签搜索和筛选
- **依赖**：现有标签系统
- **开发量**：⭐⭐ 中等
- **用户价值**：⭐⭐⭐⭐ 高 — 提升信息组织效率

### 5. 📊 统一时间线（Life Feed）
- **描述**：将足迹、账单、日记合并在一个时间轴上
- **功能点**：
  - 按时间倒序混合展示所有记录
  - 每条记录的类型图标区分（📍地点 / 💰账单 / 📝日记 / ✅打卡）
  - 示例："2026-05-20 在北京吃了顿火锅 ¥200"
  - 类似微信朋友圈的时间线体验
  - 按类型筛选（只看账单 / 只看日记）
- **依赖**：记账、日记、足迹模块
- **开发量**：⭐⭐⭐ 较大
- **用户价值**：⭐⭐⭐⭐ 高 — 一站式回顾生活

### 6. 🎯 习惯打卡
- **描述**：每日习惯追踪工具
- **功能点**：
  - 自定义习惯列表（喝水、运动、阅读、早睡…）
  - 一键打卡完成（类似记账的便捷性）
  - 连续天数统计 + 最长连续记录
  - 日历热力图展示打卡情况
  - 打卡提醒通知
- **依赖**：无（独立模块）
- **开发量**：⭐⭐⭐ 中等
- **用户价值**：⭐⭐⭐⭐ 高 — 提升日活和打开率

### 7. 🖼️ 图片附件功能
- **描述**：为各模块添加图片支持
- **功能点**：
  - 记账时附上小票/菜品照片
  - 日记时附上风景照
  - 地点亮时附上打卡照
  - 图片压缩存储（base64 存 localStorage 或转 blob URL）
  - 图片预览（支持缩放、滑动查看）
- **依赖**：RecordForm、日记表单、地图页面
- **开发量**：⭐⭐⭐ 中等偏大
- **用户价值**：⭐⭐⭐ 中高 — 增强记录的真实感

---

## P2 — 低优先级（锦上添花、差异化亮点）

### 8. 📤 数据导出
- **描述**：让用户拥有自己的数据
- **功能点**：
  - 导出 Excel 明细（月度/年度账单）
  - 导出 PDF 年度报告（排版精美）
  - 导出 JSON 全量备份（可导入恢复）
  - 批量导出图片附件
- **依赖**：所有数据模块
- **开发量**：⭐⭐ 中等
- **用户价值**：⭐⭐⭐ 中等 — 信任感和安全感

### 9. 🌙 深色模式
- **描述**：全局暗色主题支持
- **功能点**：
  - CSS 变量驱动的主题切换（light / dark / 跟随系统）
  - 所有页面适配深色背景
  - ECharts 图表深色主题
  - 自动记住用户偏好
- **依赖**：全局样式
- **开发量**：⭐⭐⭐ 较大（涉及每个页面）
- **用户价值**：⭐⭐⭐ 中等 — 夜间使用体验

### 10. 🔔 提醒通知
- **描述**：智能提醒系统
- **功能点**：
  - 每日记账提醒（可设时间，默认 22:00）
  - 习惯打卡提醒
  - 账单日提醒（信用卡还款、房租日）
  - 自定义提醒文案
- **依赖**：Notification API / 后台定时任务
- **开发量**：⭐⭐ 小
- **用户价值**：⭐⭐⭐ 中等 — 提升留存

### 11. 🎯 目标储蓄
- **描述**：存钱目标追踪
- **功能点**：
  - 创建储蓄目标（名称 + 目标金额 + 截止日期）
  - 可视化进度圆环（已存 / 目标）
  - 每笔收入可选择"转入"某个目标
  - 达成庆祝动画
- **依赖**：记账模块（收入数据）
- **开发量**：⭐⭐ 小
- **用户价值**：⭐⭐⭐ 中等 — 增加正向激励
