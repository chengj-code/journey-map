# 移动端 UI 现代化重设计 Spec

## Why
当前应用的首页直接展示地图，视觉层次单一、缺乏现代感；"我的"页面信息展示简陋。需要参照现代金融 App 的设计语言（圆角卡片、深浅配色、清晰层级），重新打造具有吸引力的移动端首页和个人中心，提升用户体验和视觉效果。

## What Changes
- **首页重构**：从地图直展改为**仪表盘式首页**，地图功能降级为入口卡片
- **个人中心重设计**：采用现代化卡片布局，增强信息展示和交互体验
- **新增地图入口**：在首页以醒目的卡片/图标形式提供地图功能入口
- **UI 风格统一**：采用圆角卡片、柔和阴影、深色主题点缀的现代设计语言
- **保持现有功能**：所有业务逻辑不变，仅重构 UI 层

## Impact
- Affected specs: map-enhancement-statistics (需调整路由结构)
- Affected code:
  - `src/views/home/index.vue` - 完全重写为仪表盘式首页
  - `src/views/user/index.vue` - 完全重写为现代化个人中心
  - `src/views/layout/index.vue` - 可能微调 TabBar 样式
  - `src/styles/` - 可能新增全局样式变量

## ADDED Requirements

### Requirement: 现代化首页仪表盘
系统 SHALL 提供一个现代化的首页，以卡片式布局展示核心功能和数据概览：

#### Scenario: 首页加载
- **WHEN** 用户访问首页
- **THEN** 页面显示以下区域（从上到下）：

**1. 顶部导航区**
```
┌─────────────────────────────────────┐
│ 🗺️ Journey Map    🔍  🔔          │
│ (Logo/标题)      (搜索) (通知)     │
└─────────────────────────────────────┘
```
- 左侧显示应用 Logo 或标题 "Journey Map"
- 右侧放置搜索图标、通知铃铛等操作入口
- 背景色：白色或极浅灰色

**2. 主视觉卡片（Hero Card）**
```
┌─────────────────────────────────────┐
│                                     │
│   📍 我的足迹                        │
│                                     │
│   已点亮 12 个地区                   │
│   省级 5 · 市级 7                   │
│                                     │
│   [ 查看地图 ]                       │
│                                     │
└─────────────────────────────────────┘
```
- 使用**深色渐变背景**（深蓝 → 深绿）或**品牌主色调**
- 大号文字展示关键统计数据（已点亮地区数）
- 副标题显示省级/市级分布
- 底部醒目的 CTA 按钮："查看地图" / "开始探索"
- 点击按钮跳转到 `/` 路由（原地图页）

**3. 快捷功能网格（Quick Actions）**
```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│   🗺️     │ │   📊     │ │   🎨     │ │   ⭐     │
│  地图     │ │  统计     │ │  图标库   │ │  收藏     │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```
- 2x2 或 3x2 的网格布局
- 每个卡片包含：图标 + 功能名称
- 可点击跳转到对应功能页面
- 圆角卡片（12-16px），带轻微阴影
- 配色：白色背景或浅彩色背景

**4. 最近点亮列表（Recent Activity）**
```
┌─────────────────────────────────────┐
│ 最近点亮                    查看全部 >│
├─────────────────────────────────────┤
│ [京] 北京市        2026-05-24       │
│ [粤] 广州市        2026-05-23       │
│ [沪] 上海市        2026-05-20       │
└─────────────────────────────────────┘
```
- 显示最近 3-5 条点亮记录
- 每条记录：省份图标(IconProvince) + 名称 + 日期
- 右上角"查看全部"链接跳转到统计页
- 列表项带分隔线或卡片样式

**5. 统计概览卡片（可选）**
```
┌─────────────────────┬─────────────────────┐
│   🏆 省级点亮        │   🏙️ 市级点亮        │
│        5           │         7            │
└─────────────────────┴─────────────────────┘
```
- 双列或单行统计卡片
- 数字使用大号字体+强调色
- 背景色可使用浅色区分

#### Scenario: 点击地图入口
- **WHEN** 用户点击 Hero Card 的 "查看地图" 按钮
- **THEN** 页面导航到地图视图（当前 home/index.vue 的内容）
- **THEN** 可通过返回按钮回到首页

### Requirement: 设计规范与视觉语言

## MODIFIED Requirements

### Requirement: 应用路由结构调整
原有的路由结构需调整：

**修改前**:
```
/layout (TabBar)
  ├── /home (首页 = 地图页)
  ├── /statistics (统计)
  └── /user (我的)
```

**修改后**:
```
/layout (TabBar)
  ├── /home (新首页 = 仪表盘)
  │   └── 点击"查看地图" → /map (原地图页)
  ├── /statistics (统计)
  └── /user (我的 - 新设计)
```

**具体改动**:
1. `src/router/root.ts`: 
   - 将现有 `home` 路由改名为 `map`
   - 创建新的 `home` 路由指向新首页组件
2. `src/views/home/index.vue`: 
   - 完全重写为仪表盘式首页
   - 原地图代码迁移到 `src/views/map/index.vue` (新建)
3. `src/views/layout/index.vue`: 
   - 保持不变（仍渲染 Home/User/Statistics）

### Requirement: 地图页面独立化
原有首页的地图功能需提取为独立页面：

**改动点**:
- 创建 `src/views/map/index.vue`（从原 home 迁移代码）
- 更新路由配置
- 地图页面保留自己的导航栏（可返回首页）

## REMOVED Requirements
无（所有功能保留，仅 UI 重构）

### Requirement: 统计页面现代化重设计
系统 SHALL 提供一个现代化的统计页面，采用折叠式面板展示点亮数据：

#### Scenario: 统计页面加载
- **WHEN** 用户访问统计页面（/statistics）
- **THEN** 页面显示以下区域（从上到下）：

**1. 导航栏**
```
┌─────────────────────────────────────┐
│  ←  点亮统计                        │
└─────────────────────────────────────┘
```
- 左侧返回按钮，点击返回上一页
- 标题"点亮统计"

**2. 统计概览卡片（Stats Overview）**
```
┌─────────────────────────────────────┐
│ ┌─────┐                             │
│ │ 📊  │   3                         │
│ └─────┘   省级 1 · 市级 2           │
└─────────────────────────────────────┘
```
- 使用与首页 Hero Card 一致的深色渐变背景
- 左侧图标区域 + 右侧数据区
- 大号数字展示总点亮数（绿色强调色 #10B981）
- 副标题显示省级/市级分布

**3. 可折叠面板列表（Collapse Panels）**

省级点亮面板：
```
┌─────────────────────────────────────┐
│ 省级点亮  (1)                    ▶  │
└─────────────────────────────────────┘
         ↓ 点击展开
┌─────────────────────────────────────┐
│ [冀] 浙江省                         │
└─────────────────────────────────────┘
```

市级点亮面板：
```
┌─────────────────────────────────────┐
│ 市级点亮  (2)                    ▶  │
└─────────────────────────────────────┘
         ↓ 点击展开
┌─────────────────────────────────────┐
│ [克] 克孜勒苏柯尔克孜自治州          │
│ [秦] 河北省/秦皇岛市                │
└─────────────────────────────────────┘
```
- 使用 `van-collapse` 组件实现折叠效果
- 默认全部收起状态（`activeNames: []`）
- 点击标题栏箭头展开/收起内容
- 面板标题包含：名称 + 数量徽章（绿色圆角标签）
- 圆角白色卡片样式 + 微阴影

**4. 列表项样式**
- 每条记录：`IconProvince` SVG 图标 + 地区名称
- **省级**：显示省份名称，图标使用对应省份数据
- **市级**：显示完整路径（省/市），图标从 `fullName` 解析所属省份
- 统一使用 `IconProvince` 组件（不再使用 34 个独立 icon 组件）

#### Scenario: 展开查看详情
- **WHEN** 用户点击"省级点亮"或"市级点亮"的标题栏
- **THEN** 对应面板展开显示详细列表
- **THEN** 再次点击可收起面板

#### Scenario: 空状态处理
- **WHEN** 某类型无点亮数据
- **THEN** 面板内显示 `van-empty` 空状态提示
