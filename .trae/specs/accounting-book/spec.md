# 记账本功能 Spec

## Why
当前应用缺少个人财务管理功能，用户无法记录和统计日常收支情况。需要新增一个完整的记账本模块，支持多账本管理、标签分类、列表/统计双模式展示、日期筛选等功能，帮助用户清晰掌握财务状况。

## What Changes
- **新增记账本模块**：包含账本管理、记录管理、标签系统三大核心功能
- **双模式展示**：列表模式（按日期倒序）+ 统计模式（图表可视化）
- **多维度筛选**：支持年/月/日筛选 + 标签分类筛选
- **数据持久化**：使用 Pinia Store + localStorage 存储所有数据
- **移动端适配**：响应式设计，符合现有 UI 风格

## Impact
- Affected specs: ui-redesign (需保持设计语言一致), tabbar-redesign (可能需要调整 TabBar)
- Affected code:
  - `src/views/accounting/` - 新增记账本页面目录
  - `src/store/accountingStore.ts` - 新增状态管理
  - `src/components/accounting/` - 新增组件
  - `src/router/root.ts` - 新增路由配置
  - `src/views/layout/index.vue` - 可能添加新入口

## ADDED Requirements

### Requirement: 账本管理系统
系统 SHALL 提供多账本支持，每个账本独立管理收支记录：

#### Scenario: 创建账本
- **WHEN** 用户点击"新建账本"按钮
- **THEN** 弹出表单对话框，输入账本名称（必填）、图标（可选）、描述（可选）
- **THEN** 创建成功后显示在账本列表中
- **THEN** 默认创建一个"日常账本"

#### Scenario: 切换账本
- **WHEN** 用户点击账本切换器
- **THEN** 显示所有已创建的账本列表
- **THEN** 选择后切换到对应账本，显示该账本的记录
- **THEN** 当前账本名称显示在页面顶部

#### Scenario: 编辑/删除账本
- **WHEN** 用户长按或点击编辑按钮
- **THEN** 可修改账本信息（名称、图标、描述）
- **THEN** 可删除空账本（无记录时允许删除）
- **THEN** 删除非空账本时提示"将同时删除所有记录"

### Requirement: 收支记录管理
系统 SHALL 提供完整的收支记录 CRUD 功能：

#### 数据结构
```typescript
interface AccountingRecord {
  id: string                    // 唯一 ID（UUID）
  bookId: string                // 所属账本 ID
  type: 'income' | 'expense'    // 类型：收入/支出
  amount: number                // 金额（正数）
  category: string              // 分类（如：餐饮、交通、工资）
  description: string           // 备注（可选）
  tags: string[]                // 标签数组
  date: string                  // 日期（YYYY-MM-DD）
  createdAt: string             // 创建时间
  updatedAt: string             // 更新时间
}
```

#### Scenario: 添加记录
- **WHEN** 用户点击"+"按钮
- **THEN** 弹出快速录入表单：
  - 类型选择（收入/支出）- 默认支出
  - 金额输入（数字键盘）
  - 分类选择（预设分类 + 自定义）
  - 日期选择（默认今天）
  - 标签选择（多选）
  - 备注输入（可选）
- **THEN** 保存后立即显示在列表中

#### Scenario: 编辑记录
- **WHEN** 用户左滑或点击某条记录的编辑按钮
- **THEN** 弹出预填充的编辑表单
- **THEN** 修改后保存更新

#### Scenario: 删除记录
- **WHEN** 用户左滑或点击删除按钮
- **THEN** 弹出确认提示"确定删除该条记录？"
- **THEN** 确认后从列表移除

### Requirement: 双模式展示
系统 SHALL 提供两种查看模式：

#### 模式一：列表模式（默认）

**布局**:
```
┌─────────────────────────────────────┐
│ [📅 2026年5月] ▼  [列表|统计]      │
├─────────────────────────────────────┤
│ 📊 本月支出: ¥2,340  收入: ¥8,000   │
├─────────────────────────────────────┤
│ 今天                               │
│ ┌─────────────────────────────────┐│
│ │ 🍜 午餐          -¥35   [餐饮]  ││
│ │ 12:30                         ││
│ └─────────────────────────────────┘│
│ ┌─────────────────────────────────┐│
│ │ 🚇 地铁          -¥6    [交通]  ││
│ │ 08:45                         ││
│ └─────────────────────────────────┘│
│ 昨天                               │
│ ┌─────────────────────────────────┐│
│ │ 💰 工资        +¥8,000  [工资]  ││
│ │ 10:00                         ││
│ └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

**规则**:
- 按消费日期倒序排列（最新在前）
- 按日期分组显示（今天、昨天、更早）
- 支持无限滚动加载
- 显示：分类图标、描述、金额、标签、时间
- 支出显示红色 `-¥xxx`，收入显示绿色 `+¥xxx`

#### 模式二：统计模式

**布局**:
```
┌─────────────────────────────────────┐
│ [📅 2026年5月] ▼  [列表|统计]      │
├─────────────────────────────────────┤
│                                     │
│     📊 月度收支统计                 │
│                                     │
│  ┌──────────┬──────────┐            │
│  │  支出     │   收入    │            │
│  │ ¥2,340   │  ¥8,000  │            │
│  └──────────┴──────────┘            │
│                                     │
│     📈 支出趋势图                   │
│  ┌─────────────────────────┐        │
│  │  (ECharts 折线图/柱状图) │        │
│  └─────────────────────────┘        │
│                                     │
│     🏷️ 标签分类占比                 │
│  ┌─────────────────────────┐        │
│  │  (ECharts 饼图/环形图)    │        │
│  └─────────────────────────┘        │
│                                     │
│  [餐饮 35%] [交通 20%] [购物 15%]   │
└─────────────────────────────────────┘
```

**图表类型**:
1. **月度总览卡片**: 支出/收入总额对比
2. **趋势图表**: ECharts 柱状图或折线图，展示每日/每周收支变化
3. **分类饼图**: ECharts 饼图或环形图，展示各标签/分类占比
4. **分类排行**: Top 5 支出/收入分类列表

### Requirement: 多维度筛选功能
系统 SHALL 支持灵活的数据筛选：

#### 时间维度筛选
- **年份筛选**: 下拉选择 2024/2025/2026...
- **月份筛选**: 下拉选择 1-12 月或"全部"
- **日期筛选**: 日历组件选择具体日期
- **快捷选项**: "本月"、"上月"、"近三月"、"今年"、"全部"

**交互方式**:
- 顶部固定筛选栏：`[2026年] [5月] [全部日期]`
- 点击展开下拉/日历选择器
- 筛选后实时更新列表/图表数据

#### 标签维度筛选
- **标签选择器**: 在列表/统计模式下显示标签过滤栏
- **支持多选**: 可同时选择多个标签（OR 关系）
- **显示条件**: 仅当记录存在标签时显示
- **重置按钮**: 一键清除所有筛选条件

### Requirement: 标签管理系统
系统 SHALL 提供完整的标签 CRUD 功能：

#### 数据结构
```typescript
interface Tag {
  id: string           // 唯一 ID
  name: string         // 标签名称
  color: string        // 标签颜色（用于图标/文字）
  icon?: string        // 标签图标（可选）
  createdAt: string    // 创建时间
}
```

#### Scenario: 标签管理入口
- **WHEN** 用户进入"标签管理"页面
- **THEN** 显示所有已创建的标签列表（网格或列表形式）
- **THEN** 每个标签显示：颜色块 + 名称 + 使用次数

#### Scenario: 创建标签
- **WHEN** 用户点击"新建标签"
- **THEN** 输入标签名称（必填，唯一性校验）
- **THEN** 选择标签颜色（预设色板或自定义）
- **THEN** 可选选择图标
- **THEN** 保存成功

#### Scenario: 编辑标签
- **WHEN** 用户点击某个标签
- **THEN** 进入编辑模式，修改名称/颜色/图标
- **THEN** 更新后所有关联记录同步更新

#### Scenario: 删除标签
- **WHEN** 用户删除标签
- **THEN** 如果有记录使用该标签，提示"X 条记录使用了此标签，是否保留标签？"
- **THEN** 选项 A：仅删除标签定义，记录中的标签引用保留（灰显）
- **THEN** 选项 B：从所有记录中移除此标签引用

#### Scenario: 给记录添加标签
- **WHEN** 用户在添加/编辑记录时
- **THEN** 显示标签选择器（可搜索、可多选）
- **THEN** 已选标签以 Chip 形式显示
- **THEN** 可快速创建新标签（内联创建）

#### Scenario: 统计模式下按标签分类
- **WHEN** 用户在统计模式查看数据
- **THEN** 图表自动按标签聚合数据
- **THEN** 饼图/柱状图展示每个标签的总金额和占比
- **THEN** 点击图例可筛选显示特定标签数据
