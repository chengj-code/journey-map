# Checklist

## 首页（仪表盘式）
- [ ] 顶部导航区显示正确：Logo/标题 + 搜索图标 + 通知铃铛
- [ ] Hero Card 使用深色渐变背景
- [ ] Hero Card 正确展示统计数据（从 mapStore 读取）
- [ ] Hero Card 的"查看地图"按钮可点击，跳转到 /map 路由
- [ ] 快捷功能网格布局正确（2x2 或 3x2）
- [ ] 每个快捷入口卡片包含图标和文字
- [ ] 最近点亮列表显示最近 3-5 条记录
- [ ] 列表项使用 IconProvince 组件显示省份图标
- [ ] "查看全部"链接可跳转到统计页
- [ ] 页面整体配色符合设计规范（浅色背景 + 深色点缀）
- [ ] 卡片圆角、阴影符合规范（12-16px 圆角 + 柔和阴影）
- [ ] 响应式布局在不同屏幕尺寸下正常显示

- [ ] 地区级联选择器功能正常

- [ ] 所有原有地图功能完整保留

- [ ] 统计数字使用大号字体和强调色
- [ ] 功能菜单列表显示正确（图标设置、历史、设置等）
- [ ] 每个菜单项有左侧图标、文字、右侧箭头

- [ ] /home 路由指向新的仪表盘首页
